# Surfshark WireGuard configs

Place Surfshark manual WireGuard `.conf` files here (one per location).

1. Log in at https://my.surfshark.com/
2. VPN → Manual setup → WireGuard
3. Download a location config (e.g. `us-dtw.conf`)
4. Copy to this VPS: `/opt/surfshark/conf/us-dtw.conf`

The portal **Surfshark** tab will list configs and can route WireGuard client traffic through the chosen server while keeping the VPS public IP reachable.
