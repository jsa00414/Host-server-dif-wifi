Setup on Windows

Download the PowerShell script and run it as Administrator (installs the VPN CA + profile), then connect.

Download Setup-ServerManagerVpn.ps1 Download CA only
  1. Open PowerShell as Administrator, then run the downloaded script (or: Set-ExecutionPolicy -Scope Process Bypass; \\path\\to\\Setup-ServerManagerVpn.ps1).
  2. Open Settings → Network & internet → VPN.
  3. Select ServerManager IKEv2 → Connect.
  4. Sign in with the username/password above.

Manual settings if you prefer the Windows UI:

VPN provider: Windows (built-in)
Connection name: ServerManager IKEv2
Server name: …
VPN type: IKEv2
Type of sign-in info: User name and password
