Setup on Windows

Click download, then open Setup-ServerManagerNas.cmd from your Downloads folder. Click Yes on the Windows security prompt.

  1. Click Download Setup above.
  2. Open your Downloads folder and double-click Setup-ServerManagerNas.cmd.
  3. Click Yes when Windows asks for administrator permission.
  4. Use This PC → Z: (ServerManager NAS) in File Explorer.

One installer file maps drive Z: via the portal public route on port 1445.
